\subsection{HMM Complexity}
The forward algorithm has time complexity $O(nm^2)$, where $n$ is the length of the
observation sequence and $m$ is the number of hidden states. At each time step, the
algorithm must compute the probability of transitioning from all states at time
$t-1$ to all states at time $t$:


\[
\alpha(x_t) = p(y_t,x_t)\,\displaystyle\sum_{x_{t-1}} p(x_t \mid x_{t-1})\,\alpha(x_{t-1}).
\]


The emission probability $p(y_t \mid x_t)$ acts only as a multiplicative constant in
this computation, so the dominant cost arises from the double summation over states,
giving $m^2$. Since this computation is performed for each of the $n$ time steps, the
overall time complexity is $O(nm^2)$.

The label distance algorithm requires we use the HMM to generate many random, but statistically likely, sequences, each of
indeterminate length. As this is a random process, a worst-case time complexity cannot
be specified without fixing the length of the generated strings. However, if the length
of a string is known, the complexity of its generation is linear in that length. Thus,
the cost of string generation can be folded into the overall complexity of the forward
algorithm, yielding the same $O(nm^2)$ bound when combined with the dynamic programming
steps.
